# Link

汎用のインラインリンク（`a` 要素 1 パーツ）です。`fandhe-frontend-headless-ui` の `link` mod が構造・アクセシビリティ（WAI-ARIA・キーボード操作）・表示状態（`data-*`）のみを提供する unstyled 部品であり、Themes 版と異なりスタイル（CSS）は一切持ちません。`external` を true にすると `target="_blank"` と `rel="noopener noreferrer"` を不可分に付与し、reverse tabnabbing を防ぎます。

スタイル済みの表示例は [Link](../themes/link.md) を参照してください。

関連 API: [fandhe-frontend-headless-ui API](../../docs/api/headless-ui-api.md)
