# JSON Tree View

JSON 風データ構造をツリー表示する部品です。`fandhe-frontend-headless-ui` の `json_tree_view` mod は `tree_view`（イシュー #753）の 12 anatomy パーツ・状態機械をそのまま再利用しつつ、`key`/`value` の 2 パーツと決定的な変換ロジックのみを追加します。Themes 版と異なりインデント・展開アイコンのスタイルを持たず、構造とアクセシビリティ属性のみを担います。

スタイル済みの表示例は [JSON Tree View](../themes/json-tree-view.md) を参照してください。

関連 API: [fandhe-frontend-headless-ui API](../../docs/api/headless-ui-api.md)
