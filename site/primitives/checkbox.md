# Checkbox

真偽値または不確定（indeterminate）の 3 値チェック状態を表すフォーム部品です。`aria-checked`/`data-state` の唯一の情報源として 3 値の型を用いるため、ARIA の偽装や不整合な値を型で防ぎます。

`fandhe-frontend-headless-ui` の `checkbox` mod が提供する構造・アクセシビリティ（WAI-ARIA・キーボード操作）・表示状態（`data-*`）のみを持つ unstyled 部品です。Themes 版が備える見た目（サイズ・colorPalette variant 等）は持たず、anatomy・ARIA・`data-*` のみを提供します。CSS は利用者が当てます。

スタイル済みの表示例は [Checkbox](../themes/checkbox.md) を参照してください。

関連 API: [fandhe-frontend-headless-ui API](../../docs/api/headless-ui-api.md)
