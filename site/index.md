## はじめる

目的に応じて、以下の 3 つの入口から進んでください。

### Getting Started

`fw new` でのプロジェクト作成からビルド・ブラウザ確認までを最短経路で
たどる入門ガイドです。[クイックスタートに進む](getting-started/quickstart/)

### Guides

コンポーネントの作成方法・既存ページへの部分埋め込み・ビュー遷移など、
目的別の実践ガイド群です。[ガイド一覧を見る](guides/)

### API Reference

コンポーネント API・ハイドレーション API など、公開 API の仕様リファレン
スです。[API リファレンスを見る](api/component-api/)
