# Timer

`fandhe-frontend-pre-styled-ui` の `timer` mod が提供するスタイル済み Timer 部品です。

分:秒のセグメントを中央揃えで縦積み表示し、値（`item-value`）は大きめの引き締まった太字、ラベル（`item-label`）は小さめの控えめ色で小文字のまま表示します。区切り（`separator`）は値の行に揃えて配置します。`completed` 状態になると値が強調色（accent）に切り替わります。操作用の `action-trigger`（開始・一時停止・リセット等）は枠線・角丸を持つ outline ボタン相当で、ホバー・キーボードフォーカスリングを備えます。
