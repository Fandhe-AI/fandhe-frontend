# Pagination

`fandhe-frontend-pre-styled-ui` の `pagination` mod が提供するスタイル済み Pagination 部品です。

ページ番号によるナビゲーション部品です。item は data-selected マーカー + aria-current="page" で現在ページを表し、root のみへ variant クラスが付く複合部品の統一方針に従います。1 件ずつの切り替えには [Carousel](carousel.md) を検討してください。`root_with` を使うとページボタンを隙間なく横一列に連結する `Attached` variant を opt-in で指定できます。

関連 API: [fandhe-frontend-pre-styled-ui API](../../docs/api/pre-styled-ui-api.md) / [fandhe-frontend-headless-ui API](../../docs/api/headless-ui-api.md)
