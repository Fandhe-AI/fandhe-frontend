# Donut Chart

`fandhe-frontend-pre-styled-ui` の `donut_chart` mod が提供するスタイル済み Donut Chart 部品です。

イシュー #2084 で shadcn/ui Charts（pie、11 バリアント）と突合し、セパレータ有無・値/カテゴリラベルの内側/外側配置・セグメント強調（active_index）・中央テキスト（center_text）の静的バリアントを `DonutChartProps` の純追加で補完しました。マウス追従ツールチップ・hover 強調・期間切替・凡例トグルのような実行時インタラクションは対象外（#2128/#2132）です。

関連 API: [fandhe-frontend-pre-styled-ui API](../../docs/api/pre-styled-ui-api.md)
