# Calendar

`fandhe-frontend-pre-styled-ui` の `calendar` mod が提供するスタイル済み Calendar 部品です。Today / Clear のようなプリセット操作行は `button` 部品との合成で再現できます。枠線なし・大セル月表示は Examples 節を参照してください。週・日の時間軸ビューは `table` 部品との合成で再現できます（Examples 節参照）。

関連 API: [fandhe-frontend-pre-styled-ui API](../../docs/api/pre-styled-ui-api.md) / [fandhe-frontend-headless-ui API](../../docs/api/headless-ui-api.md)
