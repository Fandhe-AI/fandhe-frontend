# Icon

`fandhe-frontend-pre-styled-ui` の `icon` mod が提供するスタイル済み Icon 部品です。

SVG アイコンを表示する部品です。label を指定すると role="img" + aria-label で意味のあるアイコンとして扱われ、未指定（既定）なら装飾用途として aria-hidden="true" が付与されます。fill="currentColor" を固定付与するため祖先の color プロパティで着色します。size は Xs〜Xl の 5 段（既定 Md）で、chakra-ui 同名段の実寸に整合しています。

関連 API: [fandhe-frontend-pre-styled-ui API](../../docs/api/pre-styled-ui-api.md)
