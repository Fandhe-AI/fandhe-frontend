# Table

`fandhe-frontend-pre-styled-ui` の `table` mod が提供するスタイル済み Table 部品です。

表形式データを表示する部品です。TableVariant（Line/Outline）で外枠・区切り線を、striped（bool）で縞模様表示を、sticky_header（bool）で column-header（th）の position: sticky 表示を切り替えます。column_header は scope="col" を関数側で固定し呼び出し側の偽装を除去します。

関連 API: [fandhe-frontend-pre-styled-ui API](../../docs/api/pre-styled-ui-api.md)
