# Color Swatch

`fandhe-frontend-pre-styled-ui` の `color_swatch` mod が提供するスタイル済み Color Swatch 部品です。

検証済みの Color 型から色見本を表示する部品です。検証済み型経由でのみ色値を受け取るため、任意の CSS カラー文字列を直接渡すことはできません。SwatchShape（Square/Circle/Rounded）で外形を切り替えられ、size（Xs〜Xl の 5 段、既定 Md）でサイズを切り替えられます。内側 1px の輪郭リングにより、淡色や半透明色でも外形が判別できます。

関連 API: [fandhe-frontend-pre-styled-ui API](../../docs/api/pre-styled-ui-api.md)
