# Data List

`fandhe-frontend-pre-styled-ui` の `data_list` mod が提供するスタイル済み Data List 部品です。

ラベルと値の対を一覧表示する部品です。DataListOrientation（Vertical/Horizontal）でラベル・値の並びを切り替えられます。統計指標の強調表示には [Stat](stat.md) を検討してください。

size（xs〜xl、既定 md。chakra-ui の sm/md/lg・Radix Themes の 1〜3 に対応）で gap・文字サイズが連動して変化し、variant（subtle/bold、既定 subtle）でラベル・値の強調配色を切り替えられます（chakra-ui の subtle/bold に対応）。Horizontal 時のラベル列幅は 120px に固定され、値セルはバッジ・リンク・アイコン等を横並びで配置できます。

関連 API: [fandhe-frontend-pre-styled-ui API](../../docs/api/pre-styled-ui-api.md)
