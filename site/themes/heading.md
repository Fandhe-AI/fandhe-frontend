# Heading

`fandhe-frontend-pre-styled-ui` の `heading` mod が提供するスタイル済み Heading 部品です。

size（xs〜xl4 の 8 段階）に加え、イシュー #2056 で shadcn/ui Typography と突合し weight（normal/medium/semibold（既定）/bold）軸と、呼び出し側が明示的に付与したときのみ下罫線が出る `data-bordered` opt-in 状態（shadcn h2 の `border-b pb-2` 相当）を追加しました。letter-spacing・レイアウトユーティリティ（text-center 等）は既存基準（chakra-ui / Radix Themes）を維持しています。

関連 API: [fandhe-frontend-pre-styled-ui API](../../docs/api/pre-styled-ui-api.md)
