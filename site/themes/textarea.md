# Textarea

`fandhe-frontend-pre-styled-ui` の `textarea` mod が提供するスタイル済み Textarea 部品です。

> [!NOTE]
> Anatomy は共有スコープ `field` のパーツ構成として導出されます。ラベル・補助テキスト・エラーテキスト・必須マークの型階層は [Field](./field.md) が提供します。複数のフィールドをまとめるグループ化は [Fieldset](./fieldset.md) が提供します。

関連 API: [fandhe-frontend-pre-styled-ui API](../../docs/api/pre-styled-ui-api.md)
