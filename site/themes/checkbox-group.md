# Checkbox Group

`fandhe-frontend-pre-styled-ui` の `checkbox_group` mod が提供するスタイル済み Checkbox Group 部品です。

複数選択の選択肢グループです。[Radio Group](radio-group.md) と対称の構造を持ちますが、状態機械には「0 個以上の項目が同時選択される」複数選択状態機械を使い、ネイティブ `<input type="checkbox">` は [Checkbox](checkbox.md) の hidden-input をそのまま再利用します。

関連 API: [fandhe-frontend-pre-styled-ui API](../../docs/api/pre-styled-ui-api.md) / [fandhe-frontend-headless-ui API](../../docs/api/headless-ui-api.md)
