# Avatar

`fandhe-frontend-pre-styled-ui` の `avatar` mod が提供するスタイル済み Avatar 部品です。

> [!NOTE]
> 本ページの Features / Examples / Accessibility と API Reference の引数表は
> Phase 4（#945〜#948）で充填予定です。現時点では Demo（SSR 静的掲示）と、
> headless-ui のパーツ構成から機械導出した Anatomy / `data-*` 属性表 /
> CSS 変数表のみを掲載しています。
>
> `Avatar` の Demo は `ImageStatus` を固定し、画像読み込み成功時の表示と
> フォールバック（イニシャル等）表示の両方を掲示しています。
